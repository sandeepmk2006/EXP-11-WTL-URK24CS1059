Welcome!

Students from grades 9–12 present projects in Physics, Chemistry, Biology and Environment. Every action on this site runs a MongoDB Node.js driver call on the projects collection of ScienceFairDB. Run node server.js to use a live MongoDB server. On GitHub Pages the same calls run against an in-browser collection.

Find Projects — find()

Register a Project — insertOne()

Judge / Remove — updateOne() & deleteOne()

Register three projects and list Physics — insertMany() + find()

Execute app.js — full CRUD cycle

$ node app.js

Driver calls used by this site

const { MongoClient, ObjectId } = require('mongodb');
const client = new MongoClient('mongodb://127.0.0.1:27017');
await client.connect();
const projects = client.db('ScienceFairDB').collection('projects');

await projects.insertOne({ title, student, category, grade, score });     // Register
await projects.find({ category: 'Physics' }).toArray();                   // Projects
await projects.updateOne({ _id: new ObjectId(id) }, { $set: { score } }); // Judge
await projects.deleteOne({ _id: new ObjectId(id) });                      // Remove
